# Ojasv Issar · portfolio

Personal site of Ojasv Issar, data scientist and AI/ML engineer in Vancouver, BC.
Live at **[ojasvissar.tech](https://ojasvissar.tech)**.

A single-page trail guide: painted hero, about and field credential, services signpost,
project field diary, client reviews, work-experience survey map, toolkit tree rings,
education, publications, and a contact postcard with a booking calendar. The footer is a
contour mountain whose pins link back to every section. Day and night themes follow the
visitor's clock.

Plain HTML, CSS and JavaScript, no build step.

```
index.html          the main page
blog.html           field notes (blog)
resume.html         résumé viewer (PDF on a contour map)
css/style.css       all styles, day and night
js/script.js        interactions and generated scenery (maps, contours, diary, footer)
assets/
  hero/             painted hero layers and birds
  photos/           portrait, campus, lake and trail photos
  logos/            client and employer logos
  projects/         project diary figures (three per project)
  stamps/           postcard stamp
  icons/            favicons and app icons (tiger stamp)
  social/           Open Graph preview image
  docs/             résumé PDF
favicon.ico, site.webmanifest, robots.txt, sitemap.xml, CNAME
```

Run locally with any static server, e.g. `python3 -m http.server`.
