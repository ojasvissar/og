Reddit UBC Reporter

Serverless GenAI · Hackathon winner · Jan 2026

Reddit UBC Reporter turns a week of r/UBC into one readable digest. A dual-model AWS Bedrock pipeline has Llama 3 sort every post into categories with a confidence score, then hands the week to Claude Sonnet to write an abstractive summary that lands in your inbox.

Built with a team for a hackathon, which it won. Four independent Lambda functions on AWS SAM, EventBridge scheduling, S3 persistence and Postmark for email.

Github ↗ Hackathon winner

Crop Yield Forecasting

Vision Transformer · Climate ML · 2025

A reimplementation of MMST-ViT, a multi-modal spatial-temporal vision transformer that fuses satellite imagery with weather data to forecast crop yield. Then the fun part: stress testing it against the weather it was never trained for.

I partitioned the data into heatwave, drought and extreme-rainfall regimes, measured how RMSE degrades under distribution shift, and retrained with climate augmentation: temperature offsets, rainfall scaling and extreme-year oversampling.

Github ↗

Asteroid Hazard Classifier

Classification · Imbalanced data · Nov 2025

A binary classifier for potentially hazardous objects, trained on 958,524 asteroid records from NASA/JPL. Almost none of them are hazardous, which is great for the planet and terrible for a naive model.

Recursive feature elimination and SMOTENC handle the severe class imbalance, with XGBoost and random forest ensembles on top. Eccentricity and perihelion distance came out as the two strongest risk predictors. Technically, planetary defense.

Github ↗

DisasterDash

Dashboard · Data viz · UBC MDS · 2026

An interactive analytics dashboard over EM-DAT, the international disaster database. Researchers and policymakers can explore disaster records by event type, geography and time without writing a line of code.

Built in Plotly Dash for DSCI 532 at UBC, backed by a fully reproducible data pipeline with automated preprocessing.

Github ↗

Global Temperature Forecasting

Forecasting · Time series · Dec 2025

222 years of Berkeley Earth land temperature records, and one question: what does 2030 look like? I benchmarked ordinary least squares, random forest and kernel SVR on RMSE, MAE and R².

SVR projects 2030 land temperature at 10.56°C, roughly 2°C above the 1951 to 1980 baseline. Containerised with Docker, validated with pytest and written up as a reproducible Quarto report.
